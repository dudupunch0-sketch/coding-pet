# PMD SpriteCollab Sneasel sample theme

This directory contains 128x128 static PNG extracts generated from PMD SpriteCollab animation sheets for use as coding-pet sample characters.

- Source directory: `https://raw.githubusercontent.com/PMDCollab/SpriteCollab/master/sprite/0215/`
- Theme id: `pmd-sneasel`
- Upstream project: https://github.com/PMDCollab/SpriteCollab
- License: CC BY-NC 4.0; see `../PMDCOLLAB_LICENSE.md` and the upstream SpriteCollab license. Do not treat these as company-owned production art.
- Credits: preserved in `credits.txt`.

Mood mapping:
- `idle`: `Idle-Anim.png`
- `typing`: `Walk-Anim.png`
- `celebrate`: `Pose-Anim.png`
- `alert`: `Cringe-Anim.png`
- `thinking`: `LookUp-Anim.png`
- `sleepy`: `Sleep-Anim.png`
- `sad`: `Pain-Anim.png`
