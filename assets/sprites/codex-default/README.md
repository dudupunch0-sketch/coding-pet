# codex-default sprite theme

Last verified locally: 2026-06-02

This is the built-in default PNG sprite theme for coding-pet.
It is original project art generated from `scripts/generate_codex_default_sprites.py`;
it is not a copied OpenAI, Codex, Petdex, or codex-pets.net asset.

- Size: 128x128 PNG with transparent background
- Moods: idle, typing, celebrate, alert, thinking, sleepy, sad
- Intended use: offline-safe Codex-style default companion theme
- Usage policy: original generated sample art for this repository; replace it with an
  approved imported pet package when the deployment requires a specific brand asset.

Packaging must install all seven PNGs under
`share/coding-pet/assets/sprites/codex-default/`.

The older `classic/` text sprites remain as a headless/fallback theme.
